# Terencher Android v0.1.0

اولین نسخهٔ اندروید **سیستم مدیریت ترنچر** — بازنویسی کامل اپ دسکتاپ PyQt6 بهصورت اپ موبایل بومی.

The first Android release of the **Terencher** trenching-management system — a full rewrite of the PyQt6 desktop app as a native mobile app.

---

## ✨ امکانات / Features

| صفحه | توضیح |
| --- | --- |
| **داشبورد** | سود خالص، شمارش پروژه/ماشین/اپراتور، پروژههای اخیر |
| **پروژهها** | CRUD کامل، نوار پیشرفت مالی، فیلتر وضعیت، جستجو |
| **ماشینآلات** | CRUD کامل شامل سوخت، نگهداری، عمق/عرض خندق، سرعت، وزن |
| **اپراتورها** | CRUD کامل شامل دستمزد ساعتی و اضافهکاری |
| **مالی** | دفتر درآمد/هزینه، دستهبندی، موجودی، اتصال به پروژه |
| **گزارشها** | تفکیک وضعیت، هزینه بر اساس دسته، پروژههای شاخص، خروجی CSV |
| **تنظیمات** | زبان، پوسته، نسخه، محل ذخیرهٔ داده |

---

## 🎨 طراحی / Design

- **Glassmorphism** — سطوح شیشهای مات با `backdrop-filter`، حاشیهٔ نورانی و سایهٔ نرم
- **پسزمینهٔ aurora متحرک** — چهار لکهٔ رنگی با انیمیشن نرم + بافت نویز ظریف
- **حرکتهای فنری** — ترنزیشنهای `cubic-bezier` روی لمس، تبها و فرمها
- **حالت تاریک/روشن** — با تشخیص خودکار تنظیمات سیستم
- **راستچین کامل** — چرخش خودکار RTL↔LTR همراه با تغییر زبان

---

- فارسی و انگلیسی، قابل تغییر در لحظه بدون راهاندازی مجدد

## 🦀 فناوری / Tech Stack

| لایه | فناوری |
| --- | --- |
| هستهٔ منطق و دیتابیس | **Rust** (`terencher-core`) |
| ذخیرهسازی | **SQLite** (rusqlite, حالت WAL) |
| پوستهٔ اپ | **Tauri 2** (Android) |
| رابط کاربری | ES Modules + CSS خالص |

- هیچ وابستگی فریمورکی در هستهٔ Rust نیست؛ روی هاست قابل تست است
- کاملاً **آفلاین** — بدون هیچ درخواست شبکهای
- دادهها در پوشهٔ خصوصی اپ (`app_data_dir/terencher.db`) — بدون نیاز به مجوز حافظه
